# Steam Review Lab

[English](README.md) · **Русский** · [Español](README.es.md)

Локальный инструмент для исследования публичных отзывов Steam **по любой игре**. Введите App ID, выберите период и ограничение объёма, затем изучайте время публикаций, игровой опыт, активность авторов и повторяющиеся тексты.

Стек: **Vite+, React, TypeScript, Mantine, Recharts и Express**. Интерфейс доступен на русском, английском и испанском. Выбор языка сохраняется в браузере и не сбрасывает текущий анализ.

Не нужны регистрация, внешний сервер баз данных или API-ключ Steam. Приложение не публикует данные и не отправляет их в облачный аналитический сервис.

## Быстрый запуск

Потребуются npm и **Node.js из диапазонов `^22.18.0 || ^24.11.0 || >=26.0.0`**. Рекомендуется Node.js 24 LTS.

```sh
npm ci
npm run dev
```

Откройте **http://127.0.0.1:5173**. Терминал должен оставаться открытым. Для остановки нажмите `Ctrl+C`.

Production-сборка для запуска на своём компьютере:

```sh
npm run build
npm start
```

Node-сервер необходим в обоих режимах: он обслуживает API загрузки. Нельзя просто открыть `index.html` или разместить только папку `dist/` на статическом хостинге.

## Использование

1. Введите числовой **App ID** или ссылку вида `https://store.steampowered.com/app/440/`.
2. Выберите максимум **1 000, 10 000, 50 000** отзывов или произвольное число от 1 до 50 000. Ограничение общее для положительных и отрицательных отзывов.
3. Выберите всё время или диапазон дат. Последняя календарная дата включается целиком; все границы рассчитываются в **UTC**.
4. При желании нажмите **«Проверить объём»**. Приложение запросит одну страницу размером в один отзыв, чтобы получить количество подходящих отзывов до основной загрузки.
5. Нажмите **«Загрузить отзывы»**. Можно остановить загрузку и продолжить позже, в том числе после перезапуска приложения.
6. Переключайтесь между положительными, отрицательными и всеми отзывами. Язык отзывов и период анализа выбираются отдельно от языка интерфейса.

Загрузка начинается с **самых новых** подходящих отзывов. Если доступных отзывов больше установленного лимита, результат — ограниченная недавняя выборка. Это не случайная выборка и не полная история; интерфейс явно отмечает неполные данные.

## Возможности анализа

| Раздел        | Возможности                                                                                                                                           |
| ------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| Обзор         | Количество отзывов и авторов, медианы времени игры и длины текста, гистограммы, облако слов и пар слов.                                               |
| Публикации    | Интервалы по дням, часам, 15 минутам, 5 минутам и минутам; выбор точных дат и времени; переход от дня к часам и минутам.                              |
| Плотные серии | До десяти наиболее плотных непересекающихся скользящих окон, включая серии на границе двух часов.                                                     |
| Совпадения    | Группы одинаковых нормализованных текстов, поиск, минимальная длина, сортировка по количеству, длине и близости во времени; раскрытие состава группы. |
| Опыт авторов  | Количество уникальных авторов с 1, 2, 3 и далее публичными отзывами; переход к их отзывам.                                                            |
| Отзывы        | Поиск, сортировка, страницы, публичные ссылки по желанию и JSON-экспорт выбранных записей.                                                            |

Нажатие на столбец гистограммы или слово фильтрует список отзывов. Выбор временного интервала меняет область всего анализа. Кнопка **«Весь период»** сбрасывает временной фильтр.

### Определения

- Время при отзыве — `author.playtime_at_review`, в минутах. Оно отделено от текущего общего времени игры.
- Количество отзывов автора — `author.num_reviews` на момент загрузки, включая отзыв на эту игру. Это не возраст аккаунта и не количество отзывов на дату публикации.
- Пропущенные значения исключаются из медиан и не превращаются в нули.
- Слова — последовательности букв с возможными внутренними дефисами и апострофами; BBCode и ссылки удаляются. Для языков без пробелов подсчёт приблизительный.
- В облаке считается число отзывов, содержащих слово, а не количество его повторений внутри одного текста. Удаляются служебные слова русского, английского и испанского; лемматизации нет.
- Точные совпадения игнорируют BBCode, ссылки, пунктуацию, регистр и различие «ё/е». Числа сохраняются. Семантическое сходство и перефразирование не определяются.
- Временные интервалы имеют вид `[начало, конец)`: начало включено, конец исключён. Календарь переводит последнюю выбранную дату в полночь следующего дня.

## Ограничения загрузки и Steam

Источник — официальный [GetAppReviews](https://partner.steamgames.com/doc/webapi/IUserReviewsService#GetAppReviews), с курсорной пагинацией и страницами до 100 отзывов.

**50 000 — ограничение приложения, а не гарантированная квота Steam.** Для такого объёма нужно около 500 успешных запросов, иногда дополнительные запросы для проверки конца, повторов и пересекающихся страниц. При стандартной паузе 1,5 секунды это как минимум примерно 12,5 минуты, плюс задержки сети и ограничения Steam. Приложение не предполагает официального фиксированного лимита анонимных запросов в минуту.

Загрузчик:

- Сортирует по дате создания (`filter: 1`), чтобы курсорный обход мог завершиться.
- Включает все языки, обе оценки, все способы получения игры и off-topic отзывы.
- Использует общую очередь для предварительных запросов и загрузок; одновременно выполняется одна основная загрузка.
- Учитывает `Retry-After`, увеличивает паузу при HTTP 429, серверных ошибках и тайм-аутах; не более шести попыток на страницу.
- Сохраняет страницы и курсор локально, удаляет дубли по ID отзыва.
- Останавливается при достижении лимита, пустой странице, ручной остановке или ошибке; остановленную сессию можно продолжить.
- Выявляет курсор, который не продвинулся, и не зацикливает запросы.

Steam может кэшировать анонимные ответы до десяти минут. Издательский ключ, связанный с игрой, может повысить лимит запросов, но не гарантирует непрерывную загрузку. Название игры получается по возможности: если метаданные недоступны, остаётся подпись `App <id>`.

## Хранение и приватность

Данные каждой сессии находятся только на компьютере:

```text
.data/<session-id>/
  state.json       # параметры, курсор и состояние загрузки
  reviews.jsonl    # исходные публичные отзывы, по одной JSON-записи на строку
```

`.data/`, `.env`, `node_modules/`, `dist/` и `.vite-plus/` исключены из Git. Репозиторий не содержит скачанных отзывов, реальных идентификаторов аккаунтов, секретов или отчёта по конкретной игре. Тестовые записи синтетические.

Сервер слушает `127.0.0.1`. Нет аналитики, облачного хранилища и внешних шрифтов. Запросы к Steam отправляются с вашего компьютера. Сервер рассчитан на локальную работу, не имеет авторизации и не предназначен для открытия в Интернет.

Ссылки на авторов скрыты по умолчанию. При JSON-экспорте Steam ID и ID отзывов по умолчанию удаляются, авторы получают псевдонимы внутри экспорта. **Это удаление идентификаторов, а не полная анонимизация**: текст и время публикации могут содержать личные сведения. В исходном локальном кэше сохраняются оригинальные публичные записи.

Для удаления сессии используйте корзину. Для удаления всех загрузок остановите сервер и удалите `.data/`.

## Настройки

Скопируйте `.env.example` в `.env`, если хотите изменить значения:

```dotenv
PORT=5173
STEAM_REQUEST_DELAY_MS=1500
# DATA_DIR=.data
# STEAM_WEB_API_KEY=
```

| Переменная               | По умолчанию | Назначение                                                                                        |
| ------------------------ | ------------ | ------------------------------------------------------------------------------------------------- |
| `PORT`                   | `5173`       | Порт локального сервера.                                                                          |
| `STEAM_REQUEST_DELAY_MS` | `1500`       | Пауза между запросами; минимум 500 мс.                                                            |
| `DATA_DIR`               | `.data`      | Папка кэша относительно корня проекта. Если меняете путь, исключите новую папку из Git.           |
| `STEAM_WEB_API_KEY`      | Не задан     | Необязательный серверный ключ. Не добавляйте префикс `VITE_` и не храните ключ в клиентском коде. |

Не запускайте несколько серверов с одной папкой `DATA_DIR`.

## Разработка и инструменты

```sh
npm run dev          # Express и ядро Vite+ в одном процессе
npm run check        # Oxfmt, Oxlint и проверка типов
npm run lint         # Линтер; предупреждения считаются ошибкой проверки
npm run lint:fix     # Автоматические исправления линтера
npm run format       # Форматирование Oxfmt
npm run format:check # Проверка форматирования без записи
npm run typecheck    # Проверка типов через Vite+
npm test             # Vitest; без сетевых запросов к Steam
npm run build        # Проверки и production-сборка
npm start            # Локальный запуск production-сборки
```

Vite+ закреплён по версии; сервер использует соответствующий алиас `@voidzero-dev/vite-plus-core`. Отдельный Prettier удалён. Настройки находятся в `vite.config.ts`:

- Oxlint: корректность, TypeScript, React и hooks, доступность, импорты, неиспользуемые переменные, `no-debugger`, `no-var`, `prefer-const`, строгое сравнение, ключи React и зависимости hooks.
- Проверка типов: включены `typeAware` и `typeCheck`.
- Oxfmt: два пробела, одинарные кавычки, точки с запятой, завершающие запятые, 100 символов и LF.
- Vitest: окружение Node, файлы `tests/**/*.test.ts`.

Глобально устанавливать `vp` не нужно. Для приложения используйте `npm run dev` или `npx vp run dev`; команда `vp dev` сама по себе не запускает Express API. Git hooks и глобальные настройки среды не устанавливаются.

Тесты проверяют даты, курсоры, отсутствующие поля, пагинацию, остановку и продолжение, восстановление после перезапуска, повреждённый хвост кэша, повторы запросов, серии публикаций, совпадения, удаление идентификаторов и локализацию. Загрузка 50 000 записей проверяется на 500 имитированных страницах без обращения к Steam.

src/App.tsx                    # форма, история и прогресс
src/components/Dashboard.tsx   # разделы анализа

## Локализация

Язык интерфейса не меняет язык фильтруемых отзывов. Исходные отзывы и названия игр не переводятся автоматически. Числа, даты, календарь, подписи доступности, статусы и известные ошибки следуют выбранному языку; границы времени остаются в UTC.

При первом запуске учитываются языки браузера; если подходящего нет, выбирается английский. Сохранённый выбор имеет приоритет. Переводы находятся в `shared/messages.ts`, чистые функции — в `shared/i18n.ts`, React-контекст — в `src/i18n.tsx`. Неизвестные внешние сообщения об ошибках показываются без изменений. Поля JSON-экспорта сохраняют стабильные названия.

## Интерпретация и ограничения

Программа помогает проверять гипотезы, но не доказывает накрутку. Единственный отзыв, короткий текст, повтор фразы или всплеск публикаций могут объясняться релизом, стримами, рекламой, мемами и цитатами.

Доступны только текущие версии сохранившихся публичных отзывов. Удалённые записи и предыдущие редакции восстановить нельзя. Длительная загрузка не является неизменным историческим снимком: отзывы и количество совпадений могут меняться в процессе.

GetAppReviews не предоставляет дату регистрации, закрытость профиля или количество купленных игр. Приложение не запускает скрытый сбор всех профилей и не определяет «чистые» аккаунты.

Анализ выполняется в памяти браузера: до 50 000 отзывов, страницы текстов и максимум 2 000 столбцов временного графика. Попарного семантического сравнения нет. Реальная загрузка 50 000 отзывов не использовалась как релизный тест; большие тексты могут замедлить слабые компьютеры.

## Решение проблем

- HTTP 429: дождитесь автоматического повтора или остановите загрузку и продолжите позже.
- Нет названия игры: метаданные могут быть недоступны; загрузка по App ID всё равно может работать.
- Нет отзывов: проверьте App ID и даты UTC; у демо и DLC бывают отдельные идентификаторы.
- Порт занят: измените `PORT` в `.env` и перезапустите сервер.
- Браузер не подключается: оставьте сервер запущенным и используйте адрес из терминала.
- После перезапуска загрузка остановлена: откройте сессию и продолжите; сохранённые страницы остаются на диске.
